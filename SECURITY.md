# Security Policy

## Supported Versions

We provide security updates for the following versions of `gowa-php`:

| Version | Supported          |
| ------- | ------------------ |
| 1.x     | :white_check_mark: |
| < 1.0   | :x:                |

## Reporting a Vulnerability

If you discover a potential security vulnerability within `gowa-php`, please **do not create a public issue**. Publicly disclosing a vulnerability can put users at risk.

Instead, please report the vulnerability privately:

- **Email**: Send details to `security@fazz.ai` (or open a private security advisory on GitHub).
- **Details to Include**:
  - A description of the vulnerability and its potential impact.
  - Step-by-step instructions or proof-of-concept (PoC) code to reproduce the issue.
  - Affected version(s) of `gowa-php`.

## Response Timeline

- **Acknowledgement**: We will acknowledge receipt of your vulnerability report within **48 hours**.
- **Assessment**: We will assess the report, investigate the impact, and keep you informed of our progress.
- **Resolution**: Once a fix is verified, we will release a security patch update as quickly as possible and disclose the vulnerability responsibly.

Thank you for helping keep `gowa-php` and its ecosystem secure!
